# App_Nasa
Proyecto para la nasa en donde se desarrollara un juego para niños en 36horas

Objetivo final:
  El equipo tiene que enviar información de:
    Investigaciones biologicas
    Datos ambientales
    Datos geologicos

Roles
  Comandante: es el usuario
  Cientifico: Recolectar info
  Ingeniero: Mantenimiento de la nave
  Medico: Curar a los tripulantes


Datos
  Energia
  Protección contra radiacción
  Soporte Vital
  
Eventos                        Afectación
Tormenta de arena              Soporte Vital
Tormenta solar                 Soporte Vital
Falla electrica                Energia
